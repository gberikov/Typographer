# Typographer

Типограф для русского языка на .NET: кавычки-ёлочки, тире, неразрывные пробелы.

> Статус: каркас репозитория. Правила типографики ещё не реализованы.

## Использование

```csharp
using Typographer;

var text = RussianTypographer.Format("\"Привет\" - мир");
```

## Производительность

Бенчмарки — `bench/Typographer.Bench` (BenchmarkDotNet). Запуск: `dotnet run -c Release --project bench/Typographer.Bench`.

Цель:
- пропускная способность ≥ 50 млн символов/сек на эталонной машине (ниже);
- путь записи в `IBufferWriter<char>` не аллоцирует в куче.

`string.Replace` в таблице ниже — не критерий, а ориентир масштаба: это один векторизованный поиск подстроки, а не шестифазный конвейер с десятками правил и тремя буферами на текстовый сегмент, поэтому кратность к нему не может служить целью — двукратный запас над `string.Replace` физически недостижим для такого конвейера.

Прогон: 2026-09-08, 13th Gen Intel Core i9-13980HX 2.20GHz (1 CPU, 32 логических / 24 физических ядра), Windows 11 (10.0.26200.9278/25H2/2025Update/HudsonValley2), .NET SDK 10.0.400, среда выполнения .NET 10.0.11 (X64 RyuJIT x86-64-v3), BenchmarkDotNet v0.15.8. Текст — 200 повторов фрагмента с кавычками, тире, сокращениями, инициалами, единицами измерения и HTML-разметкой, 22 200 символов (`TypografBenchmarks.TextLength`).

| Method             | Mean       | Error     | StdDev     | Ratio к StringReplace | Allocated |
|------------------- |-----------:|----------:|-----------:|-----------------------:|----------:|
| StringReplace      |   8.538 us | 0.2428 us |  0.7119 us | 1.00 (ориентир)         |   88848 B |
| Html               | 165.564 us | 4.9599 us | 14.4682 us | 19.52                  |   44424 B |
| HtmlToBufferWriter | 149.070 us | 2.3522 us |  2.2002 us | 17.58                  |       0 B |

Пропускная способность (22 200 символов / Mean):

| Method             | Символов/сек |
|------------------- |-------------:|
| Html               | ≈ 134.1 млн  |
| HtmlToBufferWriter | ≈ 148.9 млн  |

**Аллокации:** цель достигнута — `HtmlToBufferWriter` показывает `Allocated` = 0 B/op после прогрева.

**Скорость:** цель достигнута — обе цифры пропускной способности (134–149 млн симв/сек) многократно превышают порог в 50 млн симв/сек.
