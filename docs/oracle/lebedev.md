## Расхождения с нашим Default

Найдено прогоном тех же 36 строк из `tools/oracle-inputs.txt` через `Typograf.PlainText`
(текущий пресет `Default`) во временной консольной программе вне репозитория. Ниже —
только факты; решения принимает план 2b/2c.

1. **Диапазон лет `1941-1945`.** Оракул оставляет дефис, наш `ru/dash/years` ставит
   длинное тире: «...ушёл в 1941-1945 гг.» → оракул `1941-1945`, Default `1941—1945`.
   Правило применяется только к 4-значным годам: `10-15 штук` оба оставляют с дефисом.

2. **Неразрывные пробелы вокруг единиц, валют, времени и символов почти везде
   отсутствуют в Default.** Оракул последовательно ставит nbsp, Default — нет ни разу:
   - единицы: `10 кг, 5 м, 100 км/ч, 3 л` → оракул `10_кг, 5_м, 100_км/ч, 3_л`, Default
     `10 кг, 5 м, 100 км/ч, 3 л` (все пробелы обычные);
   - деньги: `100 руб., 50 долл., 5 000 р.` → оракул `100_руб., 50_долл., 5_000_р.`,
     Default без единого nbsp;
   - время: `10 ч. 30 мин.` → оракул `10_ч._30_мин.`, Default `10 ч. 30 мин.`;
   - дата с месяцем словом: `9 сентября 2026` → оракул `9_сентября`, Default `9 сентября`;
   - проценты: `50 %` → оракул `50_%`, Default `50 %`;
   - номер/параграф: `№ 5`, `§ 3` → оракул `№_5`, `§_3`, Default `№ 5`, `§ 3`;
   - температура/градусы: `25 C`, `90 град.` → оракул `25_C`, `90_град.`, Default не
     трогает ни то, ни другое (при этом сам ставит nbsp не туда: `C_и`, см. п. 6).

3. **Оракул иногда оборачивает нередактируемую последовательность в HTML-тег
   `<nobr class="phone">` вместо неразрывного пробела** — для телефона (`+7`) и для
   ISO-даты (`2026-09-09`). У нас в `TextTypograf` такого механизма нет и не планировался
   (мы используем nbsp), это архитектурное решение, а не пропущенное правило.

4. **Разделение разрядов тысяч неразрывным пробелом.** `1 000 000 рублей` → оракул
   `1_000_000` (пробелы между разрядами становятся nbsp), Default оставляет обычные
   пробелы `1 000 000`.

5. **Знак умножения.** `3 x 4 = 12` → оракул `3×4` (латинское `x` между цифрами без
   пробелов превращается в `×`), Default не трогает `x` вообще: `3 x_4`.

6. **Copyright/trademark/registered и дюймы не обрабатываются.** `(c)` → оракул `©`,
   `(r)` → `<sup class="reg">®</sup>`, `(tm)` оракул тоже не трогает; `5"` → оракул `5″`
   (дюймовый знак). Default не меняет ни один из четырёх случаев.

7. **Одиночные кавычки.** `'одинарные'` → оракул `’одинарные’` (типографский апостроф
   с обеих сторон), Default оставляет прямые `'одинарные'` без изменений.

8. **Default гораздо чаще склеивает сокращение с точкой со СЛЕДУЮЩИМ словом через
   nbsp, чем оракул**, и делает это непоследовательно:
   - инициалы: `Инициалы А. С. Пушкин` → оракул `Инициалы А._С. Пушкин` (nbsp только
     между инициалами), Default `Инициалы_А._С._Пушкин` (nbsp ещё и до, и после);
   - `г. Москва` → оракул `г. Москва` (обычный пробел), Default `г._Москва`;
   - `т-щ Петров` → оракул `т-щ Петров`, Default `т-щ_Петров`;
   - при этом `г-н Иванов` у обоих с обычным пробелом одинаково — не полностью
     системная разница, а именно у Default непоследовательная.
   - похожая непоследовательность внутри самого Default: `д. 5` → nbsp (`д._5`), но
     `кв. 12` → обычный пробел (`кв. 12`) для той же конструкции «сокращение + число».

9. **Пропадает пробел перед `!`/`?`, когда это не пунктуация конца предложения, а
   часть текста/оператора.** `8 != 9` → Default `8!= 9` (пробел исчез); `и ?? и ?!` →
   Default `и?? и?!`. Оракул в обоих случаях не трогает исходные пробелы. Похоже на
   слишком широкое условие в текущем правиле скорее, чем на отсутствующее правило —
   стоит проверить отдельно.

10. **Многоточие.** `Многоточие...` → Default стягивает три точки в один символ `…`,
    оракул оставляет три точки как есть. При этом у `.... ` (четыре точки) Default не
    только не трогает точки, но и теряет предшествующий пробел: `ещё....` вместо
    `ещё ....`; оракул сохраняет обычный пробел в обоих случаях.

## Что закрыл план 2c

Прогон тех же 36 строк через `Default` и `Lebedev` после ветки `feature/bind-rules`
(правила фазы `Bind`). Ниже только факты.

**Закрыто:**

- пункт 1 — расхождение по диапазону лет вынесено в пресет: `Lebedev` даёт
  `1941-1945_гг.`, `Default` — `1941—1945_гг.`;
- пункт 2 в части единиц, денег, времени, даты и знаков: `10_кг`, `100_руб.`,
  `10_ч._30_мин.`, `9_сентября`, `№~5`, `§~3`. Знак номера и параграфа получают УЗКИЙ
  неразрывный пробел (U+202F, ГОСТ 16.4), оракул ставит обычный — расхождение осталось, но
  теперь в выборе символа, а не в наличии отбивки;
- пункт 4 — в пресете `Lebedev`: `1_000_000` (разряды разбивает `digitGrouping`,
  включённый в этом пресете), `Default` по-прежнему оставляет обычные пробелы;
- пункт 5 (знак умножения) и пункт 6 в части `(c)`, `(tm)`, `(r)` — закрыты планом 2b;
- пункт 8 в части непоследовательности внутри `Default`: `д._5, кв._12` — обе
  конструкции «сокращение + число» теперь склеиваются одинаково;
- пункт 3 в части телефона: `+7 (999) 123-45-67` → `+7_999_123-45-67`. Тег
  `<nobr class="phone">` мы не ставим намеренно — правило `Default` не создаёт разметку из
  текста (гарантия 4).

**Осталось:**

- пункт 2 в части процентов (`50 %` → `Default` `50%`, оракул `50_%`; в пресетах `Gost` и
  `Lebedev` пробел сохраняется) и температуры (`25 C` → `Default` `25 °C` с ОБЫЧНЫМ
  пробелом, оракул `25_C` — отбивки перед знаком градуса ни одно из 107 правил не требует);
- пункт 3 в части ISO-даты: оракул оборачивает её в тег, мы переставляем на
  `09.09.2026` правилом `ru/date/fromISO`;
- пункт 6 в части дюймов (`5"` остаётся прямой кавычкой) и пункт 7 (одинарные кавычки);
- пункты 9 и 10 — дефекты фазы `Scan` вокруг `delBeforePunctuation`: `8 != 9` и `и ??`
  теряют пробел, четыре точки теряют предшествующий пробел. План 2c их не касался.

**Появилось нового:** `Default` склеивает БОЛЬШЕ, чем оракул, из-за правила
`common/nbsp/beforeShortLastWord`: короткий токен с точкой оно считает концом предложения, и
любое сокращение получает неразрывный пробел слева — `Улица_ул._Ленина`, `Город_г._Москва`,
`Сокращения_т._д.`. Отличить точку конца предложения от точки сокращения без разбора смысла
нельзя (правый контекст не помогает: за сокращением часто стоит имя собственное с прописной
буквы), а лишний неразрывный пробел безвреден и не противоречит Мильчину, который требует не
отрывать сокращение от относящегося к нему слова. Принято осознанно.
